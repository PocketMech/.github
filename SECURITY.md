# Security Policy

## Supported projects

Security reports are welcome for PocketMech organization repositories, including:

- [`.github`](https://github.com/PocketMech/.github)
- [`mobile-app`](https://github.com/PocketMech/mobile-app)
- [`core`](https://github.com/PocketMech/core)
- [`sync-service`](https://github.com/PocketMech/sync-service)
- [`admin-webterminal`](https://github.com/PocketMech/admin-webterminal)
- [`api`](https://github.com/PocketMech/api)

## Reporting a vulnerability

Please use **GitHub Private Vulnerability Reporting** for the affected repository.

1. Open the repository on GitHub.
2. Go to **Security** → **Advisories** (or **Report a vulnerability**, depending on the UI).
3. Submit a private vulnerability report with enough detail to reproduce the issue.

Do **not** open a public issue for security-sensitive findings.

We do not publish a security contact email address. Use GitHub Private Vulnerability Reporting only.

## What to include

- Description of the issue and potential impact
- Steps to reproduce
- Affected repository and, if known, component (`mobile`, `core`, `sync`, `admin`, `api`)
- Any mitigations you already identified

## Response

The maintainer ([@Bercek71](https://github.com/Bercek71)) will review private reports and follow up through GitHub. Please allow reasonable time for triage before any public disclosure.
