# Support

## How to get help

Use GitHub in the repository that best matches your question:

| Need | Where |
|---|---|
| Bug | Open a bug report issue using the template |
| Feature idea | Open a feature request issue using the template |
| Contribution process | Read [CONTRIBUTING.md](CONTRIBUTING.md) |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md) — private reporting only |
| Code of Conduct | See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

## Which repository?

| Topic | Repository |
|---|---|
| Organization profile, templates, shared GitHub config | [`.github`](https://github.com/PocketMech/.github) |
| Mobile client | [`mobile-app`](https://github.com/PocketMech/mobile-app) |
| Shared types, schemas, validation, SDK | [`core`](https://github.com/PocketMech/core) |
| Synchronization | [`sync-service`](https://github.com/PocketMech/sync-service) |
| Web admin terminal | [`admin-webterminal`](https://github.com/PocketMech/admin-webterminal) |
| Serverless API | [`api`](https://github.com/PocketMech/api) |

## Before opening an issue

1. Search existing issues in the relevant repository.
2. Confirm you are using the correct repository from the table above.
3. Do not include secrets, credentials, or private operator data.
4. Remember: AeroTool is a reference aid and does not replace official maintenance documentation (AMM or equivalent).

## What we cannot help with via GitHub issues

- Operational airline / MRO procedures outside the scope of this software
- Private security disclosures (use GitHub Private Vulnerability Reporting instead)
- Direct pushes or merges into `main` / `develop` outside the documented gitflow
